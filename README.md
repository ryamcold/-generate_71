# 7.1 环绕声生成器

一个基于 Demucs 音源分离和 Ambisonics 空间音频技术的自动化工具，可将普通立体声音乐转换为 7.1 声道环绕声文件，并支持智能参数调节。

## ✨ 特性

- **智能音源分离**：使用 Demucs 模型分离人声、鼓、贝斯及其他乐器
- **环绕声场**：采用一阶 Ambisonics 技术实现平滑自然的声像移动
- **参数可调**：通过图形界面（`config_gui.py`）可灵活调整各乐器旋转速度、人声模式、LFE截止频率等
- **自动环境配置**：主脚本 `generate_71_batch_v2.py` 自动检测虚拟环境、安装依赖（使用清华源）、创建输入输出文件夹
- **GPU 加速**：自动检测 CUDA，支持 NVIDIA GPU 加速处理
- **批量处理**：一键处理 Input 文件夹中的所有音频文件
